# 📊 Predictive Churn Analysis

## Customer Churn Prediction using Machine Learning

### 📌 Project Objective
The objective of this project is to predict whether a customer is likely to churn using Machine Learning.

### 🔹 Project Workflow
- Data Loading
- Data Preprocessing
- One-Hot Encoding
- MinMax Scaling
- 80/20 Train-Test Split
- Logistic Regression
- Model Evaluation
- Churn Probability Prediction
- High-Risk Customer Identification

### 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

### 🤖 Machine Learning Model
Logistic Regression

### 📈 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

### 🎯 ROC-AUC Score
0.6805

### 📊 Additional Analysis
- Confusion Matrix
- Churn Probability
- High-Risk Customer Analysis

### 📁 Dataset
Customer churn dataset containing 800 records and 13 columns.
